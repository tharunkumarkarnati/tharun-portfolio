Infrastructure as Code

Automated repeatable cloud infrastructure across AWS and Azure using Terraform, CloudFormation and Ansible, covering networking, EKS and core cloud resources.

TerraformCloudFormationAnsibleAWSAzureEKS

Problem / scope

Cloud environments needed repeatable provisioning patterns instead of manual setup. The work covered infrastructure, networking, Kubernetes resources and supporting compute/storage services across multiple environments.

What I owned

  • Automated EKS cluster setup, networking and Kubernetes resource creation with Terraform.
  • Provisioned and managed AWS infrastructure including EC2, RDS, S3 and EKS across multi-environment deployments.
  • Used reusable Kubernetes manifests and Helm charts alongside infrastructure automation.
  • Used Ansible playbooks to deploy and manage EC2 instances and EBS volumes.
  • Applied CloudFormation and Terraform as infrastructure-as-code tools across cloud environments.
