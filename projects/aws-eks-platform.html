CASE STUDY

AWS EKS Platform

Deployed and operated 15+ microservices on AWS EKS with secure routing, autoscaling, repeatable infrastructure and controlled rollout strategies.

AWS EKSTerraformKubernetesHelmHPAPrometheusGrafana

Problem / scope

The platform needed repeatable Kubernetes infrastructure and deployment patterns capable of supporting multiple microservices while maintaining scalability, routing, observability and reliable releases.

What I owned

  • Deployed 15+ services on AWS EKS.
  • Configured ingress controllers and AWS external load balancers for secure routing and traffic segmentation.
  • Implemented Horizontal Pod Autoscaling using real-time load and performance metrics.
  • Standardized reusable Kubernetes manifests and Helm charts to reduce configuration drift.
  • Used health checks, rolling updates and canary deployment strategies for safer releases.
  • Implemented Amazon Managed Prometheus and Grafana dashboards and alerting to improve observability and incident response.
  • Automated EKS cluster setup, networking and Kubernetes resource creation with Terraform.
