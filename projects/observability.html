CASE STUDY

Observability & Monitoring

Implemented monitoring, dashboards and alerting across AWS and Azure environments using CloudWatch, Datadog, Prometheus and Grafana.

CloudWatchDatadogPrometheusGrafanaLoki

Scope

Improved operational visibility for cloud infrastructure, Kubernetes workloads and CI/CD systems.

Key contributions

  • Built real-time dashboards and alerting using Amazon Managed Prometheus and Grafana.
  • Created Datadog dashboards integrating AWS CloudWatch metrics and autoscaling events.
  • Configured CloudWatch alarms and retention policies to proactively identify bottlenecks.
  • Used Azure Monitor and Log Analytics for Azure environments.

Outcome

Improved incident response and reduced MTTR in the EKS environment through real-time visibility and alerting.
