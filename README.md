# Tharun Kumar Karnati — Portfolio

Static, single-page portfolio with individual project case-study pages.

## Deploy to Netlify
1. Push this folder to a GitHub repository.
2. In Netlify, import the repository.
3. Build command: none.
4. Publish directory: `.`
5. `netlify.toml` is included.
